# 先核验基础，再扩展章纲

本轮把“基础尚未验收却继续扩写”改为可执行的服务端限制。世界包、人物圣经或最新计划存在未解决的阻塞问题时，请求超出当前章纲范围会在调用模型前返回 `409 PLAN_GATE`；同一范围内的修订仍然允许。`deferred` 的阻塞问题也不能绕过检查。全书重生成同样检查范围，避免旧正文已经写到较后章节时自动向后铺开。此门槛不把结构校验或手动标记问题当成正式内容质量通过，既有审批和写作门禁继续生效。

## 本轮数据处理与纠错

此前 Plan65/66 在世界33、人物圣经64尚有41条阻塞时扩写到了70/90章。核对原里程碑后发现：53—54章让赵在273日签收前知晓回令送达，57—58章重复描述10000枚船票支出，63章在291日救援前已把七人写入救济所，64章把凝元费用写成元罡，66章过早撤销仍需维持到回执完成的担保，还有路线与人物知识问题。

本轮曾保存 Plan67 作局部修订，但进一步复核发现修订不完整：53—54章未被实际改正；港务书面许可不能替代医修对施术的许可；80章也不应抹去原里程碑的410日重整决定。因此 Plan67 **不作为已修复或可继续扩写的版本**。原 Plan65—67、结构复核和失败记录均保留，另有完整本地快照和文件哈希。没有用结构检查通过来宣称这些情节已通过。

当前最新提案为 **Plan68 / 世界34 / 人物圣经65**。它采用此前已有逐字段证据的 v11 候选：保留前50章细纲与三卷100章宏观规划，加入7条验收关联调整、13项开篇预算验收要求、比例成本措辞澄清，以及第17章120日近期目标和180日远期压力的区分。第15章已有顾当面指出180日截止的认知来源，没有新造消息渠道。后40章扩写从当前候选移出，原文仍在旧计划和快照中，未删除。

这里的“恢复”仅建立新提案，未把它审批为正史，也未改写旧正文。仍有41条阻塞，40项执行验收要求；下一步必须围绕基础设计和前50章逐项复评，不能生成91—100章或正文。

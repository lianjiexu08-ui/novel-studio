# 重生成章纲保留验收要求

发现：`generateOutlines` 只把区间外的前后章纲交给模型，没有传入被替换章纲。模型遗漏 `executionChecks` 时，新提案会静默丢失旧要求；既有内容评审不能代替后续逐章的要求清单。

修复：每批传入该批原章纲 `replacingOutlines`，模型看到需保留的要求与关联。服务端使用独立副本保留原要求，模型遗漏或返回空数组时自动保留；原编号的文本或关联被改写时拒绝保存，重复编号、合并后超过24项也拒绝。允许追加独立新要求；需修改原要求时走明确的设计修订路径。范围外章纲、旧计划和当前批准计划保持原样。错误发生时不保存部分新提案。

模型提示同时要求：问题关联必须直接对应对象、人物、时段及因果链；不能仅因同属旅行、资源或认知主题建立关联，无合适问题时保留独立要求即可。这段提示是语义质量指导，不等于程序已能判定任意文本的语义相关性。新提案仍须完整设计评审。

# 提案 70：人物综合中的对话知情范围

`synthesis-7/knowledge` 通过解释写道：“港口段明确侧门领箱、吴卢内线与陆沉舟兄弟对话不自动传给林辰、贺青梧”。将三者并列，容易把在场听见的兄弟对话也理解为独立视角信息。

这里保留为**综合措辞范围不清**，不认定为已经证实的章纲缺陷，也不把“不自动传给”扩大解释为报告明确断言林贺从未听见。当前两套第 49 章原文均明确：

- 林贺来复核岗交接公共入口排查范围；陆当面催弟离港，沉川说出亲见收钱签字，陆承认动作但不说条内内容。
- 林把返单和公开入口记录放在桌上，陆画图，林贺带图准备辨门。
- 章末明确：“林知道陆承认收钱签条、指过入口，但不知条内改签全貌，也未取得原账或第二片。”

这句章末原文也确实存在于 `synthesis-7` 实际收到的 `review-result/cross-3-4` 中，并非因为材料截断而缺失。原 `cross-3-4` 概括的是陆收到弟弟求见条及其他独立视角，不能据此取消后来现场获得的信息。

后续综合应保留“当面听见有限承认”与“未获改签全貌”的区别。当前不改写原报告、不修改正确章纲、不关闭任何问题，也不据此批准人物设计。同名 JSON 保存原检查及引文、两套章节完整原文、实际输入中的字节位置与哈希；本地完整检查点保存在 `characters-synthesis-dialogue-checkpoint.json`。

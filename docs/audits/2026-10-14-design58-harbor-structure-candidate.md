# 设计58候选v9：港口段的五个不同转折

v8调整四章呈现后，节奏与玄幻体验仍被要求返修。本轮不再把连续找单据作为五章共同目标，改写45—49章的主场次，并同步人物圣经、关系阶段、弧光节点及里程碑。

| 章节 | 主场次与实际变化 |
| --- | --- |
| 45 船底向着天空 | 看修船、数空位。贺付尽储备，林收回追父案的草稿；唐要等同伴，许提出不愿一直等。比号和查空旧仓合为结果回告。 |
| 46 向北的帆 | 受护修帆棚中谈工，远处商路飞舟离泊。林承认自己也想见苍冥的雪；贺收回未经同意的远航安排，工人各自选择有限工作。 |
| 47 换一条船 | 程亲自拿替船生意要求贺改扣工陈述。贺退空单、把货序交给接手船，让客户按期走，接受自己失单。 |
| 48 门内的两个人 | 外线排查只作开场结果，主体转入吴卢。卢拒绝吴替自己答应续工，吴撤回代答；两人仍未脱控，却已决定在门前各自回答。 |
| 49 弟弟留下 | 陆弟拒绝离港及继续遮掩，陆到案并交亲走入口。兄弟没有和好，入口也不等于完整改签自认。 |

吴伍、卢小满原本就在五名雇工中，这次为其补充人物条目、独立目标与关系，不增加获救人数。48章内线没有向林贺、陆或唐送出消息；50章仍须实际到门前听到二人回答，不能拿读者所知当角色全知。

世界包相对v8完全不变。飞舟仅是既有商路实体航行，原船员与燃料供能；林贺在受护公共棚内观看，不获得船票、共享护罩、额外术法或新资源。程的替船只是一项未被接受的条件，没有实际交船或付款。既有伤情、诊费、符费、修船和食宿约束保留。

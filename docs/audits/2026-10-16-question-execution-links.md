# 设计问题关联章节验收要求

只查询最新计划和当前写作计划；两者相同时只展示一次。世界包与故事设定问题必须匹配计划绑定的设计修订，大纲问题必须匹配自身修订，不能因编号相同而跨文档或跨版本继承要求。无绑定的旧计划也不能冒充当前设定。已有当前问题清单范围不变：世界包、故事设定、最新大纲；旧批准大纲自己的阻塞问题仍保留在下方审计发现中。

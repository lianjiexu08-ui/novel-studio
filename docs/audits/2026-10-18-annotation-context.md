# 新评审携带已有核对说明

此前独立核对记录只保存在作品上并在页面展示，没有进入后续模型请求。这会使后续综合继续沿用已被指出的误读。本次修复让新建或明确重新评审的任务，在创建时冻结同一设计哈希、同一领域的核对说明。

创建时核实原任务、原判定哈希、被核对原话及原文引文，再对照当前完整设计来源。快照单独绑定 SHA-256，不改变设计哈希。后续请求指纹包含快照；恢复、失败重试和重复的重新评审请求不会吸收后来新增的说明。JSON 和 SQLite 均保存整个快照，无需数据库迁移。

说明是待核实的编辑意见，不是设定事实或可引用证据。模型仍须引用本步真实来源的片段；说明不能解除返修或直接批准写作。界面将“本次评审携带的核对说明”与另行加载的独立记录区分，并可打开被核对的原批次。旧任务明确显示未携带说明。

快照上限为 40,000 个序列化字符；超限在创建时拒绝，不静默截断、不调用模型。分批、交叉检查、补读及综合报告容量为说明预留空间，原文仍完整覆盖。无说明时保留原调度和模型请求。

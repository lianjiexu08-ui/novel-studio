# 设计63故事第四批：寿储与真元账的独立核对

正式 `story/batch-4` 在因果、时间线、兑现和成长四项给出 `revise`。共同理由是第25章战后“余六成”无法推导第27—28章寿储，认为7元载起点被重置，且遗漏188日至199日的自然流逝。原始返修结果、引用与建议完整保留在同名 JSON 和正式评审中。

独立对照发现，这个数值冲突的理由不成立：

- `world/axioms/ax_05` 明确真元、元罡、寿储分账，元载只计寿储，成数按个人健康法力上限计。
- 第13章给出第19日诊察的至少7元载条件下界；第18章在第120日实际支付凝元晋阶3元载。第25章林辰的剑诀与御物仅结算真元 `8.5−2−0.5=6成`；同场0.25元载是顾峤的独立施术成本，不能移入林辰账。
- 第27章公式中的180天是199−19，已经包含188日至199日的11天；第28章第二剂后按209−19=190天扣减。没有从第25章重置寿储。

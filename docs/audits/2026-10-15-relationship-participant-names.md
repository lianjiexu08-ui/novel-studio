# 人物关系参与者展示修复

关系快照原先仅显示关系类型和值，无法直接辨认关系双方。现在章节状态接口返回当前设定中的人物姓名，质量页显示“姓名 → 姓名”及关系类型；展开保留双方稳定 ID、关系 ID 和原有来源依据。旧接口没有姓名时回退到 ID。

姓名是当前作者设定标签，不作为章节当时的角色知识，不改变关系或正文事实。作者设定、创作计划、正文事件仍分别标记，计划不能充当已发生的关系变化。

验证：原有关系来源回归增加参与者姓名断言；隔离副本全量 318 项测试通过，构建通过（仍有既有前端大包提示）。只读内存预览验证三种来源、姓名方向、计划原因及代价、正文引文、事件/版本和人物 ID；截图为 `/tmp/novel-relationship-names-ui.png`。临时预览页面和服务已关闭。

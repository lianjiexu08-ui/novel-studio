# 界面保留被综合返修标签遮住的不足

批次列表原先只有综合 `verdict`。同批出现 `revise` 与 `insufficient` 时，综合标签为返修，界面按 `inconclusive` 统计不足就会漏掉其中的不足项。原始检查没有丢失，但作者缺少直接入口。

只读概览现在从每批原始检查提取 `insufficientCriteria`，与综合标签同时返回；已完成且无不足时返回空数组，未完成时不返回。字段在契约中可选，兼容冻结旧接口，不能把缺失字段解释成已确认没有不足。此索引不包含解释、引文或原文，不增大轮询为全量报告；原有刷新令牌包含该索引。

最终报告增加“查看曾提出材料不足的批次”，可按标准打开原始批次。当前和历史任务列表也显示不足维度；统计按批次计数，说明它可与返修批次重叠，且不等于独立问题数量。已补读解决的等待仍保留为历史，不从这份索引推导当前未解决状态。旧接口缺少逐项索引时明确提示需打开批次详情核对，避免漏项被误认成零不足。

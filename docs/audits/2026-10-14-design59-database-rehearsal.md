# 数据库升级与候选设计保存演练

本次仅操作 SQLite 在线备份产生的独立副本及独立 Prisma 客户端，不重启 API，不迁移原库，不保存或批准正式设计，不调用模型。副本中的新计划和任务 ID 仅用于持久化检查，不能当作正式进度。

## 数据与导出

原库快照包含 101 个章节版本、383 条故事事件、1 份旧书稿、58 份计划、44 份内容报告和 41 个评审任务。对副本运行 `migrate-manuscript-export-snapshot.py` 后，逐表按原字段计算行摘要，18 张表的全部原值均不变；旧书稿的新字段为 NULL。重复迁移不再修改数据。

使用候选 59 v5（SHA-256 `9f45b5d61441d23aede034d22f17d09788ca099704c2bd69bdcd71adf470316c`）在副本真实数据库中保存故事圣经与计划，再断开仓储连接并重新读取：世界版本仍为 29，圣经及计划为 59，生效的已批准计划仍为 10。原设计历史、旧报告、旧评审任务、正文与采纳记录均按摘要核验未变。结构检查仍保留 41 项阻塞问题，写作门禁未放行。

旧书稿通过新版 HTTP 导出路由前后分别导出 100 章、383 条事件，完整导出对象摘要相同。其书名和创作约定仍标记 `unavailable_legacy`，未使用当前信息填补历史。

## 评审与界面

副本为世界、力量、人物、故事各创建一个版本 19 任务，重连后均正确恢复且没有完成步骤。核查所有原文批次：最大请求分别为 217,282、218,164、218,529、219,733 字符，均低于 240,000；这里只验证调度与保存，不代表模型已评审。

设计概览首次响应为 66,624,513 字节；携带返回的 `revisionToken` 再请求，得到 101 字节的未变化响应。新计划仍显示未就绪。演练未打开端口或使用当前网页会话。

首轮演练脚本未提供评审接口，创建任务时被配置校验拒绝；此为演练工具配置问题，原错误保留。补充只会抛错的模型调用接口后，从同一原始数据库备份重新演练，全部通过，实际模型调用为 0。

正式升级仍须等待现有评审写入者退出；这些结果不构成候选设计内容验收。

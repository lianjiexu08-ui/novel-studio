# 明确时辰与钟点的冲突校验

人工核对v78第26章发现“酉初19:00”：同一章明确接班人16—18时赶路、19时交班，且07—19日班与19—次日07夜班各12小时。问题是时辰名称错误，不能把实际交班提前到17时。修订稿在章纲、圣经镜像、人物关系阶段和两个里程碑共13个字段、19处统一改为“戌初”，其余内容逐字段还原对照一致，原有41条阻断问题保留。修订稿尚未写入正式设计，待当前冻结输入评审完成后与其他发现合并。

产品增加STORY_TIME_MISMATCH错误：仅检查章节storyTime里相邻的时辰与HH:MM标注，支持半角/全角冒号、括号、子时跨午夜、初/正分段；“末”只校验两小时范围。单独时辰、单独钟点、时段和分开的两个动作不推断为同一时刻。该检查不负责解析完整时间线或判断旅程与休息时长。

计划结构审核和整体设计候选校验均定位到错误章节。批准时重新核验，防止旧版本留下的通过审核绕过新检查；已批准历史计划在正式写作准备检查时也会被阻断，但历史审核与批准记录不被改写。界面沿用现有结构审核问题展示。

验证：新时间解析和应用门禁测试，连同既有计划、设计候选测试共56项通过；核心TypeScript检查通过。真实v78离线结构检查准确报告第26章的这一处错误，修订稿消除该错误且保留所有既有阻断问题。此次检查通过不代表整部作品的内容质量通过。

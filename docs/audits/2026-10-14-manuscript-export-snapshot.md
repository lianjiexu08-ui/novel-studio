# 历史书稿的元数据与设计引用冻结

确认的缺陷：导出虽然使用冻结的章节版本和设计数值版本，却仍读取当前书名、创作约定、全部设计历史，以及当前事件的 `active` 标记。后来改名、追加约定、扩展设定或替换早章会改变旧书稿附带资料。同一设计数值版本若存在后续记录，也缺少精确的冻结引用。

修复在 `ManuscriptRevision` 新增可空 `exportSnapshot`：新书稿保存冻结书名、深拷贝约定、具体世界／圣经快照 ID、当时设计历史 ID 列表和收束结果。导出按这些引用读取；旧事件按书稿章节版本保留，其 `active` 在导出内表示当时书稿内生效。书稿 `status` 仍体现当前生命周期，可由 `final` 变为 `superseded`，不承诺该状态永远不变。

旧书稿没有可靠的历史书名和约定快照，不回填当前值：相应字段返回 `null` 并标记 `unavailable_legacy`。Markdown 标注原书名未保存，JSON 文件名使用作品 ID。已冻结的设计引用缺失时明确拒绝导出。SQLite 与 PostgreSQL 参考模型均新增可空字段，SQLite 仓储重载后保持快照；既有行仍为未知元数据。
